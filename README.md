# Automated Fitness Center Management System

Production-ready backend for managing a modern fitness center.

## Technology Stack

- Java 21
- Spring Boot 3.5.15
- Spring Security
- Spring Data JPA
- MySQL
- Flyway
- JWT
- OpenAPI
- Docker
- JUnit
- Testcontainers

## Core Modules

- Authentication
- User Management
- Member Management
- Membership Management
- Payment Management
- Attendance
- Trainer Management
- Class Scheduling
- Class Booking
- Workout Management
- Notifications
- Reports

## API

Base URL:

/api/v1
